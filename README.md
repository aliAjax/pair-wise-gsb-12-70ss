# 轮胎维护台

车队轮胎管理小工具，替代白板记账：轮胎档案、备胎借还、进站保养换位。

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 功能

- **轮胎档案**：登记编号、规格、胎纹深度、仓位、装车位置；同一车同一轮位只允许一只在用胎。
- **备胎借还**：备胎离库即占用，杜绝重复派出；归还时录入实测胎纹，低于 1.6mm 报废线必须填写理由并转报废。
- **进站保养**：车辆进站保养后按轴位生成换位建议（前交叉法），确认后一次性更新四轮归属；维修中车辆的轮胎占用保留到交车。

## 代码分层

- `src/domain/fleet.ts` — 轮胎/车辆资料：类型、常量、初始档案
- `src/domain/dispatch.ts` — 调度判断：装胎、借还、报废、换位、车辆状态流转等纯函数规则
- `src/storage/localStore.ts` — 本机存储：localStorage 读写与数据回退
- `src/stores/fleet.ts` — Pinia 粘合层：页面动作 → 调度判断 → 持久化
- `src/pages/` — 三个页面：轮胎档案、备胎借还、进站保养

数据默认保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表等能力。
